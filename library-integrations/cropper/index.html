Image cropping, reactively bound

Cropper.js owns the cropper — drag, resize, pan, zoom, handles. Micra mirrors the selection geometry into state, so the live readout below reacts as you drag, and the "Crop" button turns the current selection into a PNG preview. Pick an aspect ratio to constrain the box.
